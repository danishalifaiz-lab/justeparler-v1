# JusteParler — prototype fonctionnel serveur
Python 3, sans dépendances. Lancer `python3 server.py`, ouvrir http://localhost:8000. Pour deux téléphones, déployer sur un serveur HTTPS (micro obligatoire en contexte sécurisé). Ouvrir une session Parler et une session Écouter. Appels WebRTC directs, sans simulation. STUN public, pas de TURN : certains réseaux échoueront. Sessions et association en mémoire, un seul processus. Signalements dans reports.jsonl (à protéger, accès réservé). Pas de blocage persistant, authentification durable, contrôle d'âge, limitation de débit ni équipe de modération : ne pas ouvrir au public. Les pairs WebRTC peuvent connaître leur adresse IP. Aucun enregistrement audio prévu. Aucun achat effectué. Avant lancement : HTTPS, TURN, protection anti-abus, politique de confidentialité, modération, tests Android réels. Ce projet n'est pas un APK et n'est pas hébergé.
